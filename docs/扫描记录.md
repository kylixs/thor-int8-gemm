# Triton int8 GEMM tile 扫描记录（主机2，2026-11-07）

> 每轮扫描追加一节，格式固定，方便跨轮对照。度量＝4 代表形状 TOPS 均值。

> **EN summary**: Sweep rounds on Jetson Thor (host2, idle GPU). Baselines: stock cutlass (PTX-JIT) 55.4 TOPS; cuBLAS bf16 120 TFLOPS. Round P1 = GB10 config verbatim → 73.3 (×1.32). Round P3 = full 168-config sweep → best `128×128×128 w4s3g8` **98.4 TOPS (×1.78)**; key finding: BK=128 + num_warps=4. Bit-exact vs stock (`torch.equal`). Ceiling analysis (ncu + SASS): tensor-pipe active hard-capped at 72.5%, only `IMMA.16832.S8` emitted ⇒ ~120 TOPS theoretical max, below cuBLASLt's sustained 172. Raw data: `bench/sweep_results.jsonl`.

> 基线：stock（cutlass/PTX-JIT）55.4；cuBLAS bf16 120（同形状，不同精度）。

**规律：**
- **BK=128 ＋ w4 是关键**（BK 大=K 循环次数少；w4 给 BK=128 腾寄存器/共享内存）；

- s3/s4 差异 <1%；g4/g8 差异 <1%。

## P3-2 第二轮精扫（2026-11-07 晚，邻域＋num_ctas/窄tile/BK256，15 配置）

最优仍为 `128×128×128 w4s3`（g4/g8 差异 <0.3%，98.4→98.6）；**BK=256、num_ctas=2/4、
窄 tile（64×64/128×64）全部无增益**（num_ctas 多半编译失败或更慢）⇒ 该 Triton 模板
